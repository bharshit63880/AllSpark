# Contributing to AllSpark

First off, thank you for considering contributing to AllSpark! It's people like you that make open-source platforms such a great community.

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug, please create an issue in the repository. Include details like:
* Steps to reproduce the bug
* Expected behavior vs Actual behavior
* Your operating system and Docker version

### 2. Suggesting Enhancements
Have an idea for a new microservice or feature? Open an issue and use the `enhancement` label. Describe how it would work and why it would be beneficial.

### 3. Pull Requests (Code Contributions)
1. Fork the Project
2. Create your Feature Branch (`git checkout -b feature/AmazingFeature`)
3. Commit your Changes (`git commit -m 'Add some AmazingFeature'`)
4. Push to the Branch (`git push origin feature/AmazingFeature`)
5. Open a Pull Request

## Development Guidelines
* Ensure your code works locally using `compose.dev.yaml`.
* Follow the existing code style and structure.
* Test all MongoDB and Redis connections before submitting your PR.
* Never commit `.env` or `main.conf` files containing real secrets.

Thank you for your support!
